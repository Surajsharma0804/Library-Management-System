Features

Everything you need to run a library

Built for university libraries that need real inventory management, not just a demo.

📖

Book Inventory

Full CRUD with ISBN-10/13 validation, quantity tracking, status management (available, borrowed, lost, under repair), and category organization.

🔄

Circulation Management

Issue, return, and renew books. Automatic overdue detection, configurable loan periods, and max borrow limits per student.

💰

Fine Collection

Auto-calculated fines for late returns. Staff can collect payments or waive fines with a reason. Full payment history per student.

👥

Student Management

Register students, generate login credentials, manage membership status. Students get a self-service portal for their borrows and fines.

📊

Reports & Analytics

10+ report types with CSV export. Borrow trends, popular books, overdue reports, fine summaries, and student activity logs.

🔒

Role-Based Security

Three roles — Admin, Librarian, Student — each with granular permissions. PBKDF2 password hashing, sessions, and audit logging.

Quick Start

Up and running in 30 seconds

Clone, build, run. No database setup, no configuration files, no Docker needed.

Terminal
# Clone the repository
git clone https://github.com/Surajsharma0804/Library-Management-System.git
cd Library-Management-System

# Build the project
mvn clean package

# Run the desktop app
java -jar target/library-management-system-1.0.0.jar

# Or start the web server (accessible from any device)
java -cp target/library-management-system-1.0.0.jar com.library.WebMain
# → Open http://localhost:8080

# Default login: admin / admin@123
